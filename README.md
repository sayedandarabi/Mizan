# حساب افغانستان – نسخه ۵ (بسته آزمایشی توسعه)

این پروژه یک پایه قابل اجرا برای آزمایش رابط کاربری و منطق اصلی مالی است. زبان رابط کاربری دری افغانستان است و ساختار RTL دارد. بخش‌های لایت، پرو و تجارتی در یک برنامه قرار دارند.

## پیش‌نیازها
- Node.js نسخه ۲۰ یا جدیدتر
- Android Studio و Android SDK
- حساب Supabase برای آزمایش همگام‌سازی

## نصب و اجرا
```bash
npm install
cp .env.example .env
# مقادیر پروژه Supabase را در .env درج کنید
npx expo start
```
برای اجرای آزمایش‌ها:
```bash
npm test
npm run typecheck
```

## امکانات موجود در این بسته
- رابط اولیه سه حالت لایت، پرو و تجارتی
- داشبورد با ارقام دری و نمایش افغانی/دالر
- محاسبه اعشاری مبلغ، نرخ تبدیل و فاکتور با decimal.js
- اعتبارسنجی سند حسابداری دوطرفه
- محاسبه قرض، انتقال پول، استهلاک دارایی، سفارش مشتری و مغایرت صندوق
- طرح جدول‌های قرض، سفارش مشتری، پرداخت، انتقال، دارایی ثابت و تعهدات در Supabase
- محاسبه موجودی اعشاری انبار و جلوگیری از موجودی منفی
- طرح اولیه گزارش مالی
- پایگاه محلی SQLite و صف تغییرات در زمان قطع اینترنت
- ساختار ابتدایی Supabase، جدول‌ها و سیاست‌های دسترسی
- ساختار پشتیبانی خودکار و دستی در پایگاه داده

## قابلیت‌هایی که هنوز تکمیل و تأیید نشده‌اند
این بسته را نسخه نهایی آماده نشر ندانید. موارد زیر به کار توسعه و آزمون بیشتر نیاز دارند:
1. فرم‌های کامل ثبت و ویرایش برای همه بخش‌ها
2. انتقال واقعی اطلاعات به Supabase و دریافت تغییرات از سرور
3. حل تعارض همگام‌سازی چند دستگاه و تضمین idempotency
4. روند امن ایجاد سازمان و دعوت کاربران
5. سیاست‌های سطح نقش برای نوشتن اطلاعات در Supabase
6. گزارش‌های حسابداری از روی اسناد ثبت‌شده، نه داده نمونه
7. PDF فاکتور، چاپ، پشتیبان‌گیری رمزگذاری‌شده و بازیابی
8. آزمون دستگاه‌های مختلف و بازبینی دری توسط ویراستار بومی

## امنیت
- کلید `service_role` را هرگز در برنامه موبایل نگذارید.
- فایل `.env` را نشر نکنید.
- قبل از ورود داده واقعی، سیاست‌های RLS و دسترسی هر نقش را بازبینی کنید.
- در این نسخه، اطلاعات داشبورد نمونه و نمایشی است.

## ساختار
- `src/domain`: منطق پول، فاکتور، انبار، دفترکل و گزارش
- `src/i18n`: واژه‌نامه دری و نمایش ارقام
- `src/services`: SQLite، Supabase و صف همگام‌سازی
- `supabase/migrations`: ساختار ابتدایی پایگاه داده ابری
- `tests`: آزمایش‌های محاسباتی
